Design a relational database representing geographically distributed GPU servers and AI inference requests. Given an inference request originating from a geographic region, the system should be able to identify suitable GPU servers based on GPU compatibility, GPU capacity, machine utilization, workload, model requirements, and network latency, allowing candidate servers to be ranked by estimated response time.

The project will model a geographically distributed GPU computing system used to process AI inference requests. When an inference request is received, multiple GPU servers may be capable of executing the requested model. The database will maintain information about GPU server capacity, GPU type, server utilization, model compatibility, model deployment, geographic regions, and estimated network latency between regions. This information can then be queried to identify suitable servers and rank them based on estimated response time.

The project will use the Alibaba Cluster Trace GPU v2020 dataset as its primary source of GPU server specifications and historical workload/utilization data. Because the trace does not contain geographic server information or network latency measurements, a small simulated dataset will be added for regions, network latency, AI model requirements, and inference requests. Future sprints may extend the design with more accurate queue modelling, pricing, time-varying network latency, and more detailed GPU availability information.
